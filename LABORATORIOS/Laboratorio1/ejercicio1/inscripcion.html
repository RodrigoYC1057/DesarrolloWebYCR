1. Información general

Contenido del taller

  • Estructura semántica con HTML5
  • Hojas de estilo en cascada (CSS)
  • Maquetación con Flexbox y CSS Grid
  • Formularios y validación en el cliente

Requisitos previos (en orden)

  1. Tener aprobada la materia Programación I
  2. Contar con un editor de código instalado
  3. Presentar el Laboratorio 1 concluido
  4. Realizar el pago de matrícula

Glosario básico

HTML
Lenguaje de marcado que define la estructura del contenido.
CSS
Lenguaje de estilos que define la presentación visual.
Responsive
Diseño que se adapta al tamaño de cualquier dispositivo.
